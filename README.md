# anandsomu.github.io

Anand's public portfolio — a project-first look at backend and distributed-systems work.

- **Live:** https://anandsomu.github.io
- **Stack:** a static site, no build step required to view it. `index.html` is committed
  and served by GitHub Pages as-is. All diagrams and brand logos are hand-authored /
  inlined SVG — no diagram library, no icon CDN, no trackers. Only the Inter / Fraunces /
  Space Grotesk web fonts load from Google Fonts.
- **Source is componentized:** `index.html` is generated by concatenating the HTML
  partials in `sections/` via `./build.sh` (a plain shell `cat` — no npm, no bundler).
  You never *have* to run it to host the site; run it only after editing a partial, then
  commit the regenerated `index.html`.

## Structure (see PROGRESS.md for the full map)
- `sections/*.html` — the page split into ordered partials (head, icons, nav, hero, each
  project, skills, footer). Edit these, not `index.html`.
- `build.sh` — assembles `sections/*` → `index.html`.
- `index.html` — generated output (committed so GitHub Pages needs no build).
- `assets/styles.css` — base, layout, cards, skills, footer styling.
- `assets/css/diagram.css` — the vertical interactive diagram system.
- `assets/js/*.js` — ES modules (scroll-spy, reveal, count-ups, interactive diagrams),
  loaded as `<script type="module" defer>`; fully self-contained.
- `PROGRESS.md` — living map of where each section lives + design conventions.

## Editing
1. Edit the relevant `sections/*.html` (and `assets/css` / `assets/js` if needed).
2. Run `./build.sh`.
3. Commit `index.html` **and** the changed partials. Never `git push` on Anand's behalf.

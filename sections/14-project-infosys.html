Monolith → microservices — where the backend instincts got wired in

Full-stack backend, with an Angular front-end where the product needed one.

The problem

Legacy monoliths that were painful to scale and change — every deploy was all-or-nothing, and a small feature dragged the whole app along.

What I built

Migrated those monoliths toward a microservices architecture on Spring Boot and Docker, deployed on OpenShift. I designed the service boundaries, built REST APIs with full OpenAPI docs, and the Angular front-ends that consumed them — learning to draw boundaries where the data splits and never let a shared DB quietly re-couple "independent" services.
